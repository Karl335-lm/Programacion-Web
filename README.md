## 📌 Descripción

Este repositorio contiene el desarrollo de la **Actividad 1 de Programación Web**, 
integrada por una colección de ejercicios prácticos realizados utilizando tecnologías 
fundamentales del desarrollo web.

El propósito principal de esta actividad es poner en práctica conceptos relacionados 
con la creación de páginas web, estructura de documentos HTML, diseño mediante CSS externo 
y funcionalidades dinámicas utilizando JavaScript.


---

## 🎯 Objetivos

Con esta actividad se busca:

- 🧱 Comprender la estructura básica de un documento HTML.
- 🎨 Aplicar estilos mediante CSS.
- ⚙️ Incorporar funcionalidades utilizando JavaScript.
- 🔗 Crear enlaces y navegación entre diferentes páginas.
- 🖼️ Trabajar con imágenes y recursos externos.
- 📁 Organizar correctamente los archivos de un proyecto web.
- 💡 Resolver problemas mediante lógica de programación.

---

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|------------|-----|
| 🟧 **HTML5** | Estructura y contenido de las páginas |
| 🟪 **CSS3** | Diseño, estilos y presentación |
| 🟨 **JavaScript** | Interactividad y lógica |
